# Дворцовая · Помощник официанта

Сайт: https://egorch123ls.github.io/dvortsovaya-site/

Статический сайт без сервера, платных API и токена Telegram. Работает на GitHub Pages независимо от компьютера владельца.

## Использование

- Заказ: `1: рыбник, бефтроган 2: рыбник цез с крев`. Сохраняется сразу. Первым курсом — рыбник первой персоне и цезарь второй; вторым — бефстроганов первой и рыбник второй.
- Подача внутри заказа: закуски/салаты → супы → горячее → десерты. Каждая порция еды персоны получает отдельный курс; хлеб идёт на стол в начале. Ожидание курса определяется самым долгим блюдом в нём. Напитки показаны отдельно.
- Название или `?` открывает карточку с составом: `чиз?`, `фетуч с крев`, `ч облепиха`, `ч клюква`, `ч с ч`, `сибирский сбор`.
- `??` показывает наличие: `рыбник??`.
- Опечатки и сокращения ищутся по всем словам блюда. Если совпадение неоднозначно, сайт предлагает варианты.
- `ростбиф - 6` — «Стоп и ограничения», осталось 6. Можно менять количество кнопками или вводом. При сохранении заказа остаток уменьшается; при нуле позиция становится стопом.
- `ры стоп` — закончился; `ры не стоп` или `ры гоу` — без ограничений. `н клубника 7` — 7 шотов; `н клубника без огран` — без ограничения.
- `пицца вся стоп` — все пиццы; `парик стоп` — татин и бифштекс. Несколько команд можно разделять переносами строк.
- Стейки ведутся отдельно: `стейк 190 189 340 гоу`, `стейк забрала 190`, `стейк 190 стоп`. В разделе «Стейки» `0` очищает граммовки. Повтор веса (`190 190`) означает две порции этого веса. `1: стейк 190` списывает одну.
- `старт повыш` / `стоп повыш` переключает ожидание. Диапазоны редактируются в разделе «Ожидание».
- «Исправить» заменяет текущий активный заказ и пересчитывает списания. Просмотр заказа не списывает остатки заново. «Заказ отдал» → «Завершить». Очистка истории не возвращает остатки.

## Хранение смены

Заказы, остатки и настройки сохраняются в браузере на конкретном устройстве. Автоматической синхронизации между устройствами и Telegram нет. В разделе «Ожидание» можно скачать и загрузить копию смены или восстановить предыдущую запись. Очистка данных браузера удаляет локальное хранилище.

Наличие обновляется каждый день по часовому поясу Екатеринбурга. Неотмеченная позиция не считается подтверждённым наличием. Ручная корректировка остатка имеет приоритет: исправление старого заказа не отменяет новое число.

Сохранение проходит целиком, с проверкой структуры и резервной копией. При нехватке доступен сохранённый заказ с предупреждением; отрицательные остатки не создаются.

## Разработка и публикация

Запуск из этой папки:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.cjs
```

GitHub Pages настроен на ветку `main`, папку `/`. Публикация — обычный push. Сборка и GitHub Actions не нужны. При обновлении ресурсов меняйте версию в URL скриптов и CSS в `index.html`, чтобы браузеры получали согласованную версию.

Данные меню находятся в `data.js`: актуальные позиции/цены из PDF, описания из скриптов кухни и бара, уточнения официанта. Источники отмечены в карточках. Вина, устрицы и другие согласованные дополнения выделены отдельно. Отсутствующий в источниках состав не выдумывается.

В репозиторий нельзя добавлять `.env`, токены, базы Telegram-бота и резервные копии личной смены.
